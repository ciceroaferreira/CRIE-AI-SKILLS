O que os participantes precisam

What participants need

  • Uma conta no Claude com Skills e execução de código disponíveis (em geral, planos pagos). Vale avisar antes para quem quiser assinar.
  • Notebook de preferência, com o app desktop do Claude instalado. No celular dá para acompanhar, mas a instalação é mais fácil no computador.
  • Internet estável no local para baixar o pacote (cerca de 260 KB) e usar o Claude.
  • Nenhum conhecimento técnico. Quem usa o Claude Code pode instalar com dois comandos.
  • A Claude account with Skills and code execution available (usually paid plans). Worth telling people ahead of time.
  • Preferably a laptop with the Claude desktop app installed. Phones can follow along, but installing is easier on a computer.
  • Stable Wi-Fi at the venue to download the pack (about 260 KB) and use Claude.
  • No technical knowledge. Claude Code users can install with two commands.

Segurança e limites

Safety and limits

  • As skills rodam na conta do próprio participante. Nenhum dado é enviado para os organizadores ou para o repositório.
  • Antes de ler documentos de clientes, o Claude procura dados sensíveis (SSN, contas, apólices, saúde) e pode trocá-los por marcadores.
  • As orientações seguem regras gerais dos EUA e da Flórida e marcam o que varia por estado. Não substituem advogado, contador ou compliance.
  • Planos pessoais do Claude não incluem BAA para HIPAA. Dados de saúde identificáveis exigem cuidado extra.
  • The skills run in each participant's own account. No data goes to the organizers or to the repository.
  • Before reading customer documents, Claude scans for sensitive data (SSNs, accounts, policies, health) and can replace it with placeholders.
  • Guidance follows general US and Florida rules and flags what varies by state. It doesn't replace an attorney, CPA or compliance team.
  • Personal Claude plans don't include a HIPAA BAA. Identifiable health data needs extra care.
